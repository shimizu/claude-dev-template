# 仕上げの確認

補足: $ARGUMENTS

コマンドは `CLAUDE.md` または `CLAUDE.local.md` に書かれたものを使う。

1. **実行して確かめる。** ビルド、Lint や型チェック、テストのうち、設定されているものをすべて実行する。未設定のものは省略し、報告に書く。
2. **変更を検査する。** audit サブエージェントに現在の変更の検査を依頼する。指摘が正しいかは自分でも確かめ、誤検知は理由を添えて報告する。
3. **修正する。** 依頼の範囲内の問題は直し、手順1の該当部分を再実行する。範囲外の問題は直さずに報告する。
4. **レビューを受ける。** 変更が小さく機械的なときを除き、advisor に相談して、見落としや設計上の問題を確認する。advisor を使えないセッションでは、その旨を報告に書く。
5. **案を作る。** コミットメッセージと PR 本文の案を作る。形式はリポジトリの履歴に合わせる。
6. **報告する。** 実行したコマンドと結果、未解決の指摘、確認できなかったことを正直に書く。失敗や未確認があるときは「完了」と書かない。

ユーザーの指示があるまで、コミット、push、PR の作成はしない。
