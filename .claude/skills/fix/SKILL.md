# 不具合の修正

不具合: $ARGUMENTS

内容が空なら、不具合の内容と再現手順をユーザーに質問する。

コマンドは `CLAUDE.md` または `CLAUDE.local.md` に書かれたものを使う。テストコマンドが未設定なら、先に `/setup` を提案する。

1. **再現する。** 関連するコードを読み、不具合が起きることを確かめる。再現できなければ、推測で直さず、試したことを伝えて質問する。
2. **失敗するテストを書く。** 不具合を再現するテストを追加し、期待どおりの理由で失敗することを確認する。描画の確認など自動テストが難しいときは、その理由と手動で確認する手順を示す。
3. **原因を特定する。** 症状ではなく原因を、`ファイル:行` で示す。
4. **方針を相談する。** 原因が明らかで修正が小さいときを除き、編集する前に advisor に相談する。
5. **最小限の変更で修正する。** 無関係なリファクタや整形を混ぜない。
6. **確認する。** 追加したテストと、関連する既存のテストを実行する。同じエラーが2回続いたら、繰り返さずに advisor に相談する。
7. **報告する。** 原因、変更内容、確認の結果を伝え、`/finish` を提案する。コミットはしない。

advisor を使えないセッションでは、その旨を一度だけ伝えて続ける。
